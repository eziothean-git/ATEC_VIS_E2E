# 使用官方 Terrain 系统进行课程学习训练

## 📚 为什么需要课程学习（Curriculum Learning）？

你的桥梁训练泛化能力差的原因：
1. **单一地形训练**：只在桥梁地形上训练，模型过拟合到特定场景
2. **缺少多样性**：没有见过斜坡、台阶、障碍物等其他地形
3. **难度跳跃**：直接从平地跳到复杂桥梁，梯度太大

## 🎯 课程学习解决方案

使用官方 `terrain.py` 的 **curriculum 模式**：
- **渐进式训练**：从简单到复杂
- **多样化地形**：8种不同地形类型
- **自动晋级**：成功后自动进入更难关卡

## 🚀 训练流程

### 方案1：课程学习 → 桥梁微调（推荐）

#### 阶段1：课程学习基础训练（2000 iterations）
```bash
python train.py --task=sirius_curriculum --num_envs=1024 --headless --max_iterations=2000
```

**训练过程**：
- 机器人从第一行（最简单）开始
- 成功通过 → 自动晋级到更难行
- 最终在所有40个地形块上都能行走
- 获得强大的泛化能力

#### 阶段2：桥梁环境微调（500 iterations）
```bash
# 从课程学习的权重继续，在桥梁上微调
python train.py --task=sirius_diff_vis --resume --load_run=<curriculum_run> --checkpoint=2000 --num_envs=512 --headless --max_iterations=500
```

**优势**：
- ✅ 基础能力已具备（斜坡、缝隙、障碍物）
- ✅ 只需适应桥梁特定特征（间距、宽度）
- ✅ 训练更快，泛化更好

### 方案2：直接课程学习（如果不需要特定桥梁）

如果只是想要一个能应对各种地形的通用模型：

```bash
python train.py --task=sirius_curriculum --num_envs=1024 --headless --max_iterations=3000
```

训练完成后，模型可以应对：
- 斜坡（上下）
- 台阶
- 离散障碍物
- 踏脚石
- 缝隙
- 坑洞
- 粗糙表面

## 📊 监控训练进度

### TensorBoard 关键指标

```bash
tensorboard --logdir=legged_gym/logs/sirius_curriculum
```

**监控项**：
1. **Episode/terrain_level**: 当前训练的难度级别
   - 0.0 → 1.0 表示从易到难
   - 应该看到逐渐上升的趋势

2. **Episode/rew_tracking_lin_vel**: 速度跟踪奖励
   - 应该在各难度级别都保持较高值

3. **Episode/rew_orientation**: 姿态稳定性
   - 负值，绝对值越小越好

4. **Perf/total_fps**: FPS
   - 应该保持稳定（~30-40 FPS with 1024 envs）

### 课程进度判断

训练成功的标志：
- ✅ terrain_level 达到 4-5（最高难度）
- ✅ 各种奖励在高难度下仍然稳定
- ✅ episode length 接近最大值（很少摔倒）

## ⚙️ 配置调优

### 如果训练太慢

减少难度级别：
```python
class terrain:
    num_rows = 3  # 5 → 3，只训练3个难度级别
```

### 如果某些地形类型不需要

修改地形比例：
```python
# 去掉踏脚石和坑洞，只保留前6种
terrain_proportions = [0.15, 0.3, 0.45, 0.6, 0.75, 0.9, 0.9, 0.9, 1.0]
```

### 如果想加快晋级速度

调整 curriculum 参数（在 `legged_robot.py` 中）：
```python
def _update_terrain_curriculum(self, env_ids):
    distance = torch.norm(self.root_states[env_ids, :2] - self.env_origins[env_ids, :2], dim=1)
    # 降低晋级门槛（原来是 terrain.env_length / 2）
    move_up = distance > self.terrain.env_length / 3  # 更容易晋级
```

## 🔧 故障排除

### 问题：训练卡在低难度级别

**原因**：奖励设置不合理，无法激励前进

**解决**：
1. 增加 `tracking_lin_vel` 奖励权重
2. 减少惩罚项（如 `orientation`, `torques`）
3. 检查命令速度范围是否合理

### 问题：高难度地形频繁摔倒

**原因**：难度梯度太大

**解决**：
1. 增加难度级别数：`num_rows = 5 → 8`
2. 调整 terrain_utils 中的难度参数
3. 延长 episode 时间让模型有更多尝试机会

### 问题：某些地形类型完全学不会

**原因**：该地形类型太难或与其他类型差异太大

**解决**：
1. 为该地形类型单独训练
2. 调整该地形的难度曲线
3. 增加该地形类型的训练比例
