# 深度相机常见问题解答

## ❓ 深度图中的圆形是什么？

**答：那是机器狗自己的腿或身体！**

### 原因：
- 相机安装在机器狗身体上（base body）
- 位置：机身前方 0.3m，高度 0.12m
- 朝向：向前并向下倾斜 17 度（-0.3 rad）
- 相机视野很宽（90度），所以会拍到自己的腿

### 示意图：
```
        相机 📷 (向下17°)
         ↓ \
    [机器狗身体]
       /  |  \
      腿  腿  腿  ← 这些会进入相机视野！
```

### 深度图解读：
- **圆形/弧形** = 机器狗自己的腿（距离相机很近，约 0.07-0.15m）
- **中间部分** = 地面（距离约 0.3-1.0m，取决于机器狗高度）
- **远处** = 远方物体或天空（> 10m）

## ❓ 为什么深度是负数？

**Isaac Gym 的深度值表示方式：**

### 原始数据（之前）：
- Isaac Gym 返回**负数深度**
- 例如：`-0.15` 表示物体在相机前方 0.15 米
- `-inf` 表示超出相机远平面（没有检测到物体）

### 已修复（现在）：
Demo 代码已经**自动取绝对值**：
```python
depth_abs = np.abs(depth)  # 转换为正数
```

现在深度图显示的都是正数：
- `0.07m` = 7 厘米（很近，通常是机器狗自己的腿）
- `0.5m` = 50 厘米（地面）
- `2.0m` = 2 米（远处物体）
- `inf` = 超出范围

## ❓ 标记为什么不随机器狗动？

**已修复！**

### 问题原因：
之前的代码只在开始时绘制一次标记，标记是静态的。

### 现在的解决方案：
```python
# 每 10 步更新一次标记位置
if step % 10 == 0:
    env.gym.clear_lines(env.viewer)      # 清除旧标记
    env.visualize_camera_position()       # 绘制新标记
```

### 效果：
- ✅ 红色球体和箭头会**实时跟随机器狗移动**
- ✅ 当机器狗摇摆时，相机标记也会跟着摇摆
- ✅ 每 10 步刷新一次（平衡性能和流畅度）

## 📊 深度图颜色含义

使用 **turbo colormap**（彩虹色）：

| 颜色 | 深度范围 | 含义 |
|------|----------|------|
| 🟣 紫色/深蓝 | 0-0.5m | 非常近（机器狗自己） |
| 🔵 蓝色 | 0.5-1.0m | 近（地面、近处物体） |
| 🟢 绿色 | 1.0-1.5m | 中等距离 |
| 🟡 黄色 | 1.5-2.5m | 较远 |
| 🟠 橙色 | 2.5-3.0m | 远 |
| 🔴 红色 | > 3.0m | 很远 |

## 🔧 如何避免拍到自己的腿？

### 方法 1：调高相机位置
```python
env_cfg.camera.position = [0.30, 0.0, 0.20]  # 从 0.12 改成 0.20
```

### 方法 2：减小俯仰角（更水平）
```python
env_cfg.camera.rpy = [0.0, -0.1, 0.0]  # 从 -0.3 改成 -0.1（约6度）
```

### 方法 3：减小视场角
```python
env_cfg.camera.horizontal_fov = 60  # 从 90 改成 60 度
```

### 方法 4：在代码中过滤近距离物体
```python
depth[depth < 0.2] = np.nan  # 忽略 20cm 以内的物体
```
